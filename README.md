🚀 CodeTracker Pragati

Track Your Coding Journey, Improve Your Skills!

CodeTracker Pragati is a web-based platform designed to help students monitor their coding progress and stay consistent in their programming journey.

🌟 Features

- Student Dashboard – View coding progress in one place.
- Profile Integration – Connect and view coding platform profiles.
- HackerRank Integration – Track student coding profiles.
- Progress Tracking – Monitor programming practice and achievements.
- Programming Statistics – View coding-related information through a simple dashboard.
- User-Friendly Interface – Easy to use and understand.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- AI-Assisted Development

🎯 Project Objective

To provide students with a simple platform to track their coding activities, understand their progress, and improve their programming skills through consistent practice.
